# 1. Product Architecture

## الرؤية
منصة طبية Multi-Platform لإدارة المستشفى (HMS) — Web + Windows + Android عبر قاعدة كود موحّدة.
المنتج النهائي يجب أن يشعر المستخدم بأنه **Medical Professional Software** وليس CRUD عام.

## المبادئ
1. **التصميم أولوية #1** — Design System موحّد، واجهات Responsive حقيقية (Mobile-First).
2. **الأمان أولوية #2** — Zero Trust، تحقق Server-Side من كل طلب.
3. **سير طبي حقيقي** — الطبلة الإلكترونية (Patient Chart) هي الشاشة الأهم بعد Dashboard.
4. **Codebase مشترك** — أكبر قدر من إعادة استخدام الكود عبر المنصات.
5. **دعم كامل للعربية (RTL) والإنجليزية** عبر نظام i18n.

## Users & Roles
| الدور | اختصاص |
|---|---|
| Super Admin | إدارة النظام والمستشفيات |
| Admin | إدارة مستشفى (أقسام، ردهات، مستخدمين) |
| Doctor | السجل الطبي، الملاحظات، التشخيص، الأدوية |
| Nurse | Vital Signs، ملاحظات تمريض، الإجراءات |
| Pharmacist | صرف الأدوية |
| Lab Tech | النتائج المخبرية |
| Radiology Tech | تقارير الأشعة |
| Reception | تسجيل المرضى، الدخول/الخروج |
| View-only (intern) | قراءة فقط |

## الميزات الأساسية (MVP)
- مصادقة آمنة + تفويض حسب الدور/النطاق.
- لوحة تحكم (إحصائيات، غرف، تنبيهات حرجة).
- إدارة المرضى (تسجيل، بحث، قائمة).
- **الطبلة الإلكترونية**: نظرة عامة، Vital Signs، تشخيص، ملاحظات طبيب، تمريض، أدوية، مختبر، أشعة، استشارات، إجراءات، مرفقات، جدول زمني (Timeline), خروج.
- تتبع عبر Audit Logs.
- وضع تجريبي (Demo Seed) لإظهار النظام ببيانات واقعية.

## خارطة طريق

2. PWA (تثبيت على Android).

4. تقارير وميزات متقدمة.
